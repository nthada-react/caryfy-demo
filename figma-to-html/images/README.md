## Image Optimization Tips

1. **Format**: Use WebP for modern browsers, with JPEG/PNG fallbacks
2. **Compression**: Optimize images to reduce file size
3. **Responsive**: Provide multiple sizes for different screen densities
4. **Alt Text**: Always include descriptive alt text in HTML

## Recommended Tools

- **TinyPNG** - Online image compression
- **Squoosh** - Google's image optimizer
- **ImageOptim** - Mac image optimization
- **GIMP/Photoshop** - Image editing

## File Naming

Use descriptive, lowercase filenames with hyphens:
- ✅ `hero-background.jpg`
- ✅ `team-photo-2024.jpg`
- ❌ `IMG_001.jpg`
- ❌ `Background Image.JPG`
